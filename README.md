# OncoApp

Çalıştırıp hemen görebileceğiniz tek dosyalı backend + web arayüzü.

## Hızlı Çalıştırma
```bash
npm start
```

Ardından açın: `http://localhost:3000`

## VS Code'da Çalıştırma
1. Projeyi VS Code ile açın (`File > Open Folder`).
2. Sol menüden **Run and Debug** bölümüne gelin.
3. **OncoApp: Launch Server** konfigürasyonunu seçin.
4. `F5` ile başlatın.
5. Tarayıcıdan `http://localhost:3000` adresini açın.

## VS Code Task'ları
- `Terminal > Run Task > OncoApp: npm start`
- `Terminal > Run Task > OncoApp: npm test`

## Test
```bash
npm test
```
